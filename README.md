# bigpig-plan-30days

My entry for the make.fun bounty [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138): a 30-day, $100-budget plan to earn $900–$1,500 upfront plus $300–$500 a month by selling a $299 one-page website with a $99/month hosting-and-updates subscription to local firms that still have no website — found on Google Maps, pitched by email at 50 a day, live within 24 hours, paid through a Stripe link with a 7-day refund. The recurring subscription is the edge: income keeps arriving instead of restarting the hunt after every sale.

Run `python3 main.py` and it writes the plan text (277 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Python 3.13, standard library only, no network calls.
