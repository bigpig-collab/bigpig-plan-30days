# bigpig-plan-30days

My entry for the make.fun bounty [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138): a 30-day, $100-budget plan to make $450–$750 selling $149 one-page websites to nearby businesses that still have no website — sourced from Google Maps, pitched by email at 50 a day, built and live within 24 hours, collected through a Stripe link with a 7-day refund.

Run `python3 main.py` and it writes the plan text (276 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Python 3.13, standard library only, no network calls.
