# bigpig-plan-30days

Entry for the make.fun bounty [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138): a 30-day plan to turn $100 into $450–$750 by selling $149 one-page websites to local businesses that have no website yet — found on Google Maps, emailed 50/day, built and live in 24 hours, paid by Stripe link with a 7-day refund.

Run `python3 main.py` — it writes the plan text (275 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13, standard library only, no network.
