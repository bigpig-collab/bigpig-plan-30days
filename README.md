# bigpig-plan-30days

My entry for the make.fun bounty [the-plan-make-fun-will-carry-20261122-2138](https://make.fun/competitions/the-plan-make-fun-will-carry-20261122-2138): a 30-day, $100-budget plan to earn $900–$1,500 plus $300–$500 a month by selling local firms a $299 one-page website with a $99/month hosting-and-updates subscription. Find 200 firms with no site on Maps, pitch by email at 50 a day, go live within 24 hours, take payment through a Stripe link with a 7-day refund. The edge is the recurring revenue, not the one-off sale.

The entry text (280 characters):

> Days 1-2: find 200 firms with no site on Maps. Sell a $299 one-page site, live in 24h plus $99/mo hosting/updates — Stripe link, 7-day refund. Email 50/day. $100 covers domain/hosting/email. Close 3-5 clients by day 30: $900-$1,500 plus $300-$500/mo. Edge: recurring revenue wins.

Run `python3 main.py` and it writes the plan text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Python 3.13, standard library only, no network calls.
